## Code Assistants 3.3.0

- Novo painel **Conectar IAs grátis (login + 1 toque)** no topo de "APIs IA": para as APIs grátis já pré-estabelecidas (Google Gemini, OpenRouter :free, Groq, Cerebras, NVIDIA NIM, SambaNova, Hugging Face, Cloudflare), você só abre o portal, faz o login e copia a chave.
- Botão **Colar** lê a chave direto da área de transferência (bridge nativo do Android) e o app registra o provedor sozinho — sem preencher base URL, modelo e apelido campo por campo.
- Ao conectar, o app adiciona **todos os modelos grátis** daquele provedor, testa cada um, remove o que não respondeu e **liga a troca automática de IA** para as próximas mensagens.
- Provedores adicionados depois (chaves próprias, endpoints locais ou customizados) continuam no formulário manual, como antes.

Baixe `Code-Assistants-v3.3.0.apk`. O ZIP contém o código-fonte correspondente ao commit publicado.
