## Code Assistants 3.5.2

### Correção crítica: barra lateral do Windows e erro 404

- **Identificação do Windows injetada diretamente no HTML:** o executável agora define `window.CodeAssistantsDesktop` diretamente no código da página, sem depender de carregar o arquivo `/desktop-bootstrap.js`. Isso corrige o aparecimento da barra lateral ("Este computador", projetos, diagnóstico) mesmo quando um service worker antigo intercepta requisições e retorna 404.
- **Desregistro automático de service workers antigos:** ao abrir o app no Windows, service workers de versões anteriores são desregistrados, evitando que bloqueiem chamadas à API e causem erro "Falha ao carregar gateway (404)".
- **Sem service worker no localhost:** o registro do service worker PWA continua ignorado quando rodando em `127.0.0.1`/`localhost`.

### Mesma versão no APK e no Windows

- APK e Windows publicados juntos na versão 3.5.2, com o mesmo sistema de atualização por releases do GitHub.

---

No Windows, baixe `Code-Assistants-v3.5.2.exe` ou `Code-Assistants-v3.5.2-setup.exe` (instalador recomendado). O SmartScreen pode pedir confirmação porque o arquivo não tem assinatura comercial — clique em *Mais informações* e depois em *Executar assim mesmo*. No Android, baixe `Code-Assistants-v3.5.2.apk`.
