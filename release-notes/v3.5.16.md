## Code Assistants 3.5.16

### Login no Windows funciona de verdade (sem precisar configurar .env)

- **Tela de login obrigatória ao abrir:** o aplicativo agora pede login antes de mostrar qualquer projeto ou chave. Não abre mais direto na interface.
- **Sem necessidade de configurar .env:** o login no Windows funciona localmente, direto no computador, sem exigir que você crie ou edite arquivos `.env`. O instalador prepara tudo sozinho.
- **Login com email/senha:** cadastre ou entre com sua conta; seus projetos e chaves ficam protegidos neste dispositivo.

### Correções

- **Modelos locais (Ollama / LM Studio) não causam mais erro falso:** se você não tem esses programas instalados, eles não aparecem mais como "Falhou". Adicione manualmente quando quiser usar.
- **Sincronização de versão:** UI, manifesto Android, auxiliar de build nativo e atualizador Java agora estão todos em 3.5.16.

### Publicado junto

- APK (Android), EXE (Windows) e instalador (.exe do Windows) publicados juntos na versão 3.5.16.
