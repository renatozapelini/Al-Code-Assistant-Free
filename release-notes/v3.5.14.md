## Code Assistants v3.5.14

### Login no GitHub e sistema de autenticação completo

- **Login no GitHub:** agora você pode fazer login no Code Assistants usando sua conta do GitHub (via OAuth)
- **Login com Google:** também disponível login via conta Google
- **Cadastro de usuário:** crie sua conta com email e senha para usar em qualquer dispositivo
- **Sincronização de projetos:** suas chaves de IA e configurações ficam sincronizadas entre computador e celular
- **Conta de administrador:** primeiro usuário cadastrado se torna administrador automaticamente
- **Gerenciamento de usuários:** o administrador pode ativar/desativar usuários e alterar papéis

### Como usar

1. Baixe o instalador `.exe` da release
2. Execute o instalador e siga as instruções
3. Configure o servidor de autenticação (se ainda não tem um)
4. Faça login com sua conta ou crie uma nova
5. Suas chaves de IA serão sincronizadas automaticamente

### Instalador

- O instalador substitui versões existentes automaticamente
- Seus projetos e chaves são preservados durante a atualização
- Não precisa baixar o EXE separado — o instalador cuida de tudo
