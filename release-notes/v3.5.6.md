## Code Assistants 3.5.6

### Correção crítica: barra lateral do Windows, atualização automática e login no GitHub

- **Recarregamento forçado após desregistro de service workers:** se um service worker antigo foi desregistrado, a página recarrega automaticamente para garantir que nenhuma requisição seja interceptada. Isso elimina o erro "Falha ao carregar gateway (404)" causado por service workers de versões anteriores.
- **Identificação do Windows em três camadas:** o `index.html`, o `main.tsx` e o próprio servidor do EXE injetam `window.CodeAssistantsDesktop`. Isso garante que o app se reconheça como Windows mesmo se uma camada falhar.
- **Barra lateral do Windows:** aparece corretamente com "Este computador", projetos, diagnóstico e versão do aplicativo.
- **Atualização automática no Windows:** o painel de atualizações mostra o botão "Atualizar agora" e verifica automaticamente ao abrir e a cada hora.
- **Login no GitHub no app:** a aba "Este computador → GitHub" aparece corretamente. Cole um token pessoal (fine-grained, com permissão de conteúdo) para conectar sua conta e enviar projetos diretamente ao github.com.

### Instalador substitui versão existente

- O instalador fecha o processo em execução, remove a versão anterior e instala a nova automaticamente. Seus projetos e chaves são preservados.

### Mesma versão no APK e no Windows

- APK e Windows publicados juntos na versão 3.5.6, com o mesmo sistema de atualização por releases do GitHub.

---

No Windows, baixe `Code-Assistants-v3.5.6.exe` ou `Code-Assistants-v3.5.6-setup.exe` (instalador recomendado). O SmartScreen pode pedir confirmação porque o arquivo não tem assinatura comercial — clique em *Mais informações* e depois em *Executar assim mesmo*. No Android, baixe `Code-Assistants-v3.5.6.apk`.

Se ainda aparecer erro 404 ou a barra lateral não mostrar, desinstale completamente o Code Assistants, reinicie o computador e instale novamente o instalador mais recente.
