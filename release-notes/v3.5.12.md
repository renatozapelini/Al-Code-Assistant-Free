## Code Assistants 3.5.12

### Menu sanduíche no celular (hambúrguer)

- **Menu lateral tipo sanduíche:** no aplicativo móvel (APK), o menu inferior foi substituído por um menu sanduíche que abre e fecha. Toque no botão de menu no topo direito para abrir a navegação lateral com Projetos, Chat, APIs IA, Opções e Este computador.
- **Tela mais limpa:** sem barra de navegação fixa embaixo, mais espaço para o conteúdo.

### Agrupar APIs por provedor com toggle mestre

- **Toggle mestre por provedor:** na tela de APIs IA, cada provedor (Google Gemini, OpenRouter, Groq, etc.) agora tem um botão para ativar ou desativar todos os seus modelos de uma vez.
- Não precisa entrar em cada modelo individualmente para ligar ou desligar.

### Modelos locais instalados de fábrica (Windows e Android)

- **Windows:** Ollama e LM Studio são instalados automaticamente ao abrir o aplicativo, prontos para uso offline sem chave de API. Toggle global e individual para ativar/desativar.
- **Android:** Ollama e LM Studio são descobertos automaticamente na tela de APIs IA (descoberta de provedores locais). Toque para adicionar e usar offline.

### Mesma versão no APK e no Windows

- APK e Windows publicados juntos na versão 3.5.12, com limpeza automática de cache ao atualizar.

---

No Windows, baixe `Code-Assistants-v3.5.12.exe` ou `Code-Assistants-v3.5.12-setup.exe` (instalador recomendado). O SmartScreen pode pedir confirmação porque o arquivo não tem assinatura comercial — clique em *Mais informações* e depois em *Executar assim mesmo*. No Android, baixe `Code-Assistants-v3.5.12.apk`.
