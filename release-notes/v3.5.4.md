## Code Assistants 3.5.4

### Correção crítica: barra lateral do Windows e erro 404 persistente

- **Desregistro agressivo de service workers antigos:** ao abrir o app, todos os service workers de versões anteriores são desregistrados assim que o JavaScript carrega. Isso elimina o erro "Falha ao carregar gateway (404)" causado por service workers antigos interceptando requisições.
- **Identificação do Windows como fallback no `main.tsx`:** se o HTML não injetou a identificação do Windows, o próprio ponto de entrada do React define `window.CodeAssistantsDesktop` quando rodando em localhost. Isso garante que a barra lateral apareça mesmo se a injeção no HTML falhar.
- **Meta tags anti-cache no HTML:** `Cache-Control: no-store`, `Pragma: no-cache` e `Expires: 0` impedem que o navegador use versões antigas em cache.
- **Mensagem de erro mais clara:** quando der 404 no serviço local no Windows, a tela sugere pressionar Ctrl+Shift+R e, se continuar, desinstalar e instalar novamente o instalador mais recente.

### Instalador substitui versão existente

- O instalador fecha o processo em execução, remove a versão anterior e instala a nova automaticamente. Seus projetos e chaves são preservados.

### Mesma versão no APK e no Windows

- APK e Windows publicados juntos na versão 3.5.4, com o mesmo sistema de atualização por releases do GitHub.

---

No Windows, baixe `Code-Assistants-v3.5.4.exe` ou `Code-Assistants-v3.5.4-setup.exe` (instalador recomendado). O SmartScreen pode pedir confirmação porque o arquivo não tem assinatura comercial — clique em *Mais informações* e depois em *Executar assim mesmo*. No Android, baixe `Code-Assistants-v3.5.4.apk`.

Se ainda aparecer erro 404 ou a barra lateral não mostrar, desinstale completamente o Code Assistants, reinicie o computador e instale novamente o instalador mais recente.
