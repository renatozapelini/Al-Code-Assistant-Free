## Code Assistants 3.5.8

### Modelos locais pré-instalados (Ollama e LM Studio)

- **Ollama e LM Studio instalados de fábrica:** ao abrir o aplicativo no Windows, os provedores locais Ollama (porta 11434) e LM Studio (porta 1234) são adicionados automaticamente, prontos para uso offline sem chave de API.
- **Toggle para ativar/desativar:** na aba "Este computador → Modelos locais" você pode ligar ou desligar cada provedor local individualmente.
- Funciona com Ollama, LM Studio e qualquer servidor OpenAI compatível rodando localmente.

### Mesmo sistema de atualização

- APK e Windows publicados juntos na versão 3.5.8, com limpeza automática de cache ao atualizar.

---

No Windows, baixe `Code-Assistants-v3.5.8.exe` ou `Code-Assistants-v3.5.8-setup.exe` (instalador recomendado). O SmartScreen pode pedir confirmação porque o arquivo não tem assinatura comercial — clique em *Mais informações* e depois em *Executar assim mesmo*. No Android, baixe `Code-Assistants-v3.5.8.apk`.
