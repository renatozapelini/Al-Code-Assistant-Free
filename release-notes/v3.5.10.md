## Code Assistants 3.5.10

### Versão Linux instalada de fábrica (habilitar/desativar)

- **Modelos locais Linux instalados de fábrica:** Ollama e LM Studio vêm pré-configurados para uso offline no Windows e Linux, sem chave de API nem internet.
- **Toggle global:** na aba "Este computador → Modelos locais" você pode ativar ou desativar todos os provedores locais Linux de uma vez. Quando desativado, os provedores locais são desligados; quando ativado, são recriados automaticamente.
- Cada provedor local também tem seu próprio toggle individual de ativação/desativação.

### Mesma versão no APK e no Windows

- APK e Windows publicados juntos na versão 3.5.10, com limpeza automática de cache ao atualizar, menu lateral sanduíche e modelos locais com toggle.

---

No Windows, baixe `Code-Assistants-v3.5.10.exe` ou `Code-Assistants-v3.5.10-setup.exe` (instalador recomendado). O SmartScreen pode pedir confirmação porque o arquivo não tem assinatura comercial — clique em *Mais informações* e depois em *Executar assim mesmo*. No Android, baixe `Code-Assistants-v3.5.10.apk`.
