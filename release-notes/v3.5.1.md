## Code Assistants 3.5.1

### Correção: barra lateral do Windows e erro 404

- **Injeção robusta do `desktop-bootstrap.js`:** o executável agora injeta o script que identifica o app como Windows mesmo se o HTML não tiver `</head>` (tenta `<body` e início do arquivo como fallback). Isso corrige o aparecimento da barra lateral ("Este computador", projetos, diagnóstico) na versão Windows.
- **Fallback no React:** se a injeção no HTML falhar, o próprio aplicativo tenta buscar `/desktop-bootstrap.js` e definir `window.CodeAssistantsDesktop`, recarregando a página automaticamente.
- **Sem service worker no localhost:** o registro do service worker PWA é ignorado quando rodando em `127.0.0.1`/`localhost` (sinal de que está pelo EXE), evitando que um service worker antigo bloqueie chamadas à API e cause erro 404.
- **Mensagem de erro mais clara:** quando `/api/app/overview` retorna 404 no Windows, a tela sugere pressionar **Ctrl+Shift+R** para recarregar o cache.

### Mesma versão no APK e no Windows

- APK e Windows publicados juntos na versão 3.5.1, com o mesmo sistema de atualização por releases do GitHub.
