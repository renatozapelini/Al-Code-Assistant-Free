## Code Assistants 3.5.0

### Computador (Windows)

- **Instalador para o .exe:** agora há um instalador que coloca o aplicativo no seu usuário do Windows (sem precisar de administrador), cria atalhos na área de trabalho e no menu Iniciar, e prepara as pastas de trabalho fora da instalação para que atualizar ou desinstalar não apague nada.
- **Pasta dos projetos no computador:** os projetos ficam em `Documentos\Code Assistants\Projetos`, em subpastas normais que você pode abrir no Explorer. Cada projeto tem seus arquivos de código e um `project.json` com o checkpoint da IA (esse arquivo não é enviado ao GitHub).
- **Diagnóstico de falhas:** se a janela não abrir ou mostrar erro, o aplicativo grava um log em `%LOCALAPPDATA%\Code-Assistants\logs\app.log` e mostra uma página de erro visível em `/diagnostico` (ou tente novamente na tela principal).
- **Porta alternativa:** se a porta 8790 estiver ocupada por outro programa, o aplicativo tenta as portas seguintes automaticamente.
- **Atualização continua a mesma:** consulta os releases públicos do GitHub, valida o instalador `.exe`, baixa, confere o sha256 e troca o arquivo em uso.

### GitHub no aplicativo (computador)

- **Entrar no github.com:** cole um token pessoal (fine-grained ou clássico) na tela “Este computador”. O token fica só nesta máquina, nunca é exibido de volta nem gravado em log.
- **Enviar projeto direto:** escolha um projeto salvo na pasta do computador, crie ou selecione um repositório no GitHub, e envie todos os arquivos como um commit pelo menu “Este computador → GitHub”. Nada é publicado sem você confirmar.

### Mesma versão no APK e no Windows

- APK e Windows publicados juntos na versão 3.5.0, com o mesmo sistema de atualização por releases do GitHub.

---

No Windows, baixe `Code-Assistants-v3.5.0.exe` ou `Code-Assistants-v3.5.0-setup.exe` (instalador recomendado). O SmartScreen pode pedir confirmação porque o arquivo não tem assinatura comercial — clique em *Mais informações* e depois em *Executar assim mesmo*. No Android, baixe `Code-Assistants-v3.5.0.apk`.
