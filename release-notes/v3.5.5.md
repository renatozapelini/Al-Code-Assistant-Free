## Code Assistants 3.5.5

### Correção crítica: barra lateral do Windows, atualização automática e login no GitHub

- **Identificação do Windows direto no `index.html`:** o arquivo HTML inicial agora define `window.CodeAssistantsDesktop` assim que carrega, quando detecta localhost (rodando pelo EXE). Isso garante que a barra lateral ("Este computador", projetos, diagnóstico) apareça mesmo se houver service worker antigo ou cache do navegador.
- **Atualização automática no Windows 11:** com a detecção do Windows funcionando, o painel de atualizações mostra o botão "Atualizar agora" e a verificação automática ao abrir e a cada hora.
- **Login no GitHub no app:** a aba "Este computador → GitHub" agora aparece corretamente. Cole um token pessoal (fine-grained, com permissão de conteúdo) para conectar sua conta e enviar projetos diretamente ao github.com pelo aplicativo.
- **Service workers antigos são desregistrados** ao carregar, eliminando o erro "Falha ao carregar gateway (404)".
- **Meta tags anti-cache** impedem que o navegador use versões antigas em cache.

### Instalador substitui versão existente

- O instalador fecha o processo em execução, remove a versão anterior e instala a nova automaticamente. Seus projetos e chaves são preservados.

### Mesma versão no APK e no Windows

- APK e Windows publicados juntos na versão 3.5.5, com o mesmo sistema de atualização por releases do GitHub.

---

No Windows, baixe `Code-Assistants-v3.5.5.exe` ou `Code-Assistants-v3.5.5-setup.exe` (instalador recomendado). O SmartScreen pode pedir confirmação porque o arquivo não tem assinatura comercial — clique em *Mais informações* e depois em *Executar assim mesmo*. No Android, baixe `Code-Assistants-v3.5.5.apk`.

Se ainda aparecer erro 404 ou a barra lateral não mostrar, desinstale completamente o Code Assistants, reinicie o computador e instale novamente o instalador mais recente.
