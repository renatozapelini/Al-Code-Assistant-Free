## Code Assistants 3.4.0

- **Agora no computador:** o Code Assistants ganhou um aplicativo para Windows. É o mesmo programa, com as mesmas ideias e os mesmos dados: um único `.exe` que abre a interface no seu computador e guarda chaves e projetos localmente, em `%USERPROFILE%\.qoder2api-hub`.
- **Visual de desktop:** navegação lateral fixa (Projetos, Chat, APIs IA, Ferramentas e Opções), área de trabalho mais larga e a mesma identidade escura com verde-esmeralda do APK.
- **Mesmo sistema de atualização do APK:** o aplicativo consulta os releases públicos do GitHub ao abrir e a cada hora, valida a versão e o link do instalador e mostra quando há uma versão nova. Em **Atualizar agora**, ele baixa o `.exe`, confere o tamanho e o sha256 publicado, troca o arquivo em uso e reabre sozinho. Se preferir, use **Baixar .exe direto**.
- **APK e Windows na mesma versão:** os dois são publicados juntos neste release (3.4.0) e a partir de agora seguem a mesma numeração.
- **Sem service worker no `.exe`:** a interface vem de dentro do próprio executável, então não fica presa em cache antigo depois de atualizar.
- **Nada é enviado ao GitHub:** o atualizador lê apenas a lista pública de releases. Chaves, contas e projetos nunca saem do computador.

No Windows, baixe `Code-Assistants-v3.4.0.exe` e execute. O SmartScreen pode pedir confirmação porque o arquivo não tem assinatura comercial — clique em *Mais informações* e depois em *Executar assim mesmo*. No Android, baixe `Code-Assistants-v3.4.0.apk`. O ZIP contém o código-fonte correspondente ao commit publicado.
